Gyro-Enhanced Micromouse

Autonomous maze solving using a MEMS gyroscope, ToF sensing, encoder feedback and closed-loop control.

Sensor FusionSimulinkControl

Designed and built an autonomous micromouse capable of solving complex mazes while maintaining a stable estimate of heading and position.

The key improvement was integrating a MEMS gyro into the feedback loop to reduce cumulative heading error and make high-speed turns more repeatable.

Embedded firmware, sensor integration, calibration, control-loop implementation and test-driven tuning.

Encoder odometry + IMU heading estimation + ToF wall measurements feed a closed-loop navigation stack. Bias compensation and filtered rate data improve turn accuracy.

Improved orientation consistency and more reliable autonomous maze runs, with a workflow that made sensor behaviour observable and tunable.

AUV Acoustic Communication

Chirp-FSK acoustic link for an Antarctic under-ice AUV positioning and data system.

DSPEmbedded CChirp-FSK

Developed the signal-processing subsystem for an under-ice Acoustic Positioning System designed to localise an AUV without requiring it to surface for GPS. The subsystem generates binary chirp packets, conditions the received acoustic signal, detects packet arrival and decodes payload data for timing-based localisation.

The design was shaped by the realities of Antarctic acoustic channels: multipath reflections, falling SNR with range, limited usable bandwidth and the need to process packets on embedded hardware in real time.

Responsible for the signal-processing subsystem: modulation design, waveform parameterisation, MATLAB validation, analogue receive filtering, embedded firmware architecture and the packet-detection/timestamping pipeline.

The work focused on turning the communication concept into a chain that could be implemented and tested on real embedded hardware.

  • Binary linear chirp-FSK: upchirps and downchirps encode digital symbols across a 1–5 kHz band
  • MATLAB waveform and BER testing, with a 0.3 s chirp, Tukey windowing and spectral pre-emphasis
  • Sallen–Key Butterworth analogue band-pass filter to suppress out-of-band noise before the ADC
  • Matched filtering for packet detection, followed by GCC-PHAT / IR-GCC-PHAT correlation for arrival-time estimation
  • Real-time C firmware architecture targeting embedded acquisition and decoding without offloading computation

The design validated the core communication chain in simulation and hardware tests: chirp energy was confined to the target band with zero BER in the reported noisy trials, timing correlation met the required accuracy in simulation, and the analogue filter achieved more than 20 dB out-of-band attenuation.

The resulting architecture provides a practical path from acoustic waveform design to timestamp generation for TDOA-based AUV positioning.

Rocket Telemetry

ESP32 flight transmitter, Raspberry Pi receiver and a live Flask dashboard for telemetry.

ESP32Raspberry PiFlask

Designed an end-to-end telemetry system around an ESP32 flight computer and a portable Raspberry Pi 4 ground station. The system acquires flight and status data, packages it into compact telemetry messages and presents the stream through a browser-based dashboard.

The project treats observability as part of the engineering system: live sensor values, GPS information, flight state, charts and logged data are available from the same ground-station stack for testing and post-flight analysis.

Designed and integrated the telemetry path from the embedded flight electronics through wireless transport and MQTT messaging to the Raspberry Pi ground station and Flask dashboard.

Also worked on the data schema, real-time dashboard behaviour, logging pipeline and the system interfaces needed to make the project usable as a portable field ground station.

  • ESP32 flight computer publishes sensor, GPS and system-status telemetry as compact JSON messages
  • Raspberry Pi 4 acts as the portable ground-station computer, Wi-Fi access point and MQTT host
  • Mosquitto provides the message layer, with the ground application subscribing across the rocket telemetry topic tree
  • Flask and Socket.IO push live updates to connected browsers without manual page refreshes
  • Dashboard surfaces live altitude, velocity, acceleration, orientation, battery data, GPS mapping, flight events and rolling history
  • Incoming telemetry is logged for later analysis, with the architecture designed to start automatically for field use

A complete embedded-to-browser telemetry workflow with a clearly defined message architecture and portable ground station. The system was designed to handle concurrent messaging, live visualisation and data logging while keeping the operator interface simple during testing.

The project established a reusable avionics/ground-station foundation that can be extended as additional sensors and flight features are integrated.
