FEATURED PROJECT01

Gyro-Enhanced Micromouse

Closed-loop trajectory following using an ICM-20602 gyroscope, VL53L1X ToF sensing and bias compensation for reliable maze navigation.

Sensor FusionSimulinkControl
OVERVIEW

A compact autonomous vehicle that combines inertial sensing and time-of-flight ranging to follow a maze while correcting accumulated heading error in real time.

MY ROLE

Designed the sensing and control approach, characterised gyro bias, and integrated the feedback loop with the navigation logic.

TECHNICAL APPROACH
  • ICM-20602 gyro for angular-rate estimation
  • VL53L1X ToF sensors for wall distance
  • Bias compensation and closed-loop heading control
  • Simulink modelling before hardware testing
OUTCOME

A more stable trajectory with reduced drift and more repeatable maze navigation.

EEE4113F / COMMS02

AUV Acoustic Communication

Chirp-FSK acoustic link for an Antarctic under-ice AUV positioning and data system.

DSPEmbedded CChirp-FSK
OVERVIEW

Designed a robust acoustic communication concept for an autonomous underwater vehicle operating where GPS is unavailable.

MY ROLE

Worked through waveform design, modulation choices and receiver-side signal processing for reliable low-bandwidth communication.

TECHNICAL APPROACH
  • Chirp-based signalling for time-frequency robustness
  • FSK modulation and demodulation
  • DSP filtering and detection
  • Embedded C implementation considerations
OUTCOME

A practical communication architecture balancing range, bandwidth and detection reliability.

Rocket Telemetry

ESP32 flight transmitter, Raspberry Pi receiver and a live Flask dashboard for telemetry.

ESP32Raspberry PiFlask
OVERVIEW

A lightweight flight telemetry stack that captures onboard data, sends it to a ground station and turns the stream into a live operator dashboard.

MY ROLE

Built the embedded-to-ground data path and the web dashboard used to monitor the vehicle during testing.

TECHNICAL APPROACH
  • ESP32 telemetry transmitter
  • Raspberry Pi ground receiver
  • Python/Flask dashboard
  • Live status and sensor visualisation
OUTCOME

A clear end-to-end telemetry workflow that made flight data visible and actionable during testing.
